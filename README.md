# Samara Pires — Digital Portfolio

A responsive portfolio website focused on Data Science, Machine Learning, AI and Analytics.

## Run locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a GitHub repository (for example `portfolio`).
2. Upload all files in this folder.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose `main` and `/root`, then save.
6. GitHub will provide your public portfolio URL.

## Before publishing
Replace the placeholder LinkedIn/GitHub/Google Scholar URLs in `index.html` with your real profile links.
Replace the placeholder project GitHub links with the actual repositories.
